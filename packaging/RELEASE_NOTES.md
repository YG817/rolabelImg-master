# roLabelImg 2.0.2 · Windows x64

## 新增功能

- 界面调整：中性浅色分组面板、类别下拉选项和菜单、统一按钮和列表；批量编辑、版本设置、类别管理及巡检窗口重新排版。菜单名称和快捷键分列，修复重叠。

- 区域框选编辑：Ctrl+B 拖出区域选中完整包含的可见标注，Ctrl / Shift 可追加选区。
- 批量编辑：Ctrl+M 或“修改所选”更改类别、普通矩形或旋转矩形类型；支持批量删除、撤销与重做。锁定框需先解锁。
- 单框改标签：右键双击普通框或旋转框，选择已有类别或输入新类别；仅修改点击的框，支持连续标注模式、撤销及重做。
- 单边调整：左键拖动四条边的中段调整单边，对边固定；普通框和旋转框均支持，保留旋转角度及撤销、重做。
- 大量标注性能：增加空间索引、几何缓存和绘制区域裁剪；鼠标悬停与拖动只更新变化区域，几何调整不再重新统计整张影像的类别编号，避免重复重设状态栏样式。
- 修复未打开影像时 Ctrl＋滚轮触发空影像绘制异常并退出的问题；空白画布、关闭影像和加载期间均保护缩放入口。
- 可调布局：左侧工具栏支持左右拖动宽度，收窄自动只显示图标；右侧类别、标注、导出与坐标以及影像列表支持上下分配高度，正常退出后记住布局。
- 顶部导航增加统一的细线图标，图标和菜单文字同时显示。
- 修正分隔条布局：右侧拉高时保持标题、按钮和输入项的固定间距，仅扩大列表内容或底部留白；移除类别表格固定高度。左侧最大宽度按完整图标及文字计算，收窄仍可显示纯图标，旧的过宽设置自动限制到新上限。
- 软件内更新下载：显示更新日志、下载进度、大小和速度，支持取消、重试；下载完成后可保存标注并退出安装。
- 更新检查优先读取发布附件 `update.json`，减少对 REST API 查询额度的依赖；保留已发现版本及日志，受限时仍可下载，已校验的本地安装包可离线复用。

## 修复问题

- 删除读取失败的 JSON 后，可以在影像原目录重新保存；新建空 JSON 占位文件也可直接保存。
- 保存保护检查实际文件状态，保留对未修复损坏文件及其他影像标注的保护。
- 下载更新时切换影像不会取消下载；退出软件或关闭更新窗口会取消未完成的下载。
- 区分访问拒绝与限流，按服务端等待时间暂停重复查询，连续受限时延长等待。

## 安装与升级

使用 `roLabelImg-Setup-2.0.2-win-x64.exe` 安装；绿色版完整解压 `roLabelImg-2.0.2-win-x64-portable.zip`。
旧客户端首次升级可下载新安装包；安装这一版后即可使用软件内下载更新。
安装包未签名；从旧安装版到新版的人工安装、升级验收仍需在目标电脑完成。
